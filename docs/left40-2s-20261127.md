# 后处理左移：40%速度、2秒

2026-11-27按用户要求，将靠桶并完成左视对齐后的额外左移，从20%速度、4秒改为40%速度、2秒。`missions/timed_translate.py`是参数的唯一来源，任务配置、几何计划、实际执行及运行日志统一读取该动作。

`ChassisPort`默认定时动作上限仍为20%；后处理显式使用40%上限。动作完成后仍等待禁用回传，再执行B回顶、C伸150mm。前期巡航、测距和靠近策略保持原设置。

此前20%速度下的位移记录不适用于40%新速度。因此新日志将`estimated_travel_mm_interval`置空，标记为`unmeasured_speed_profile`，保留定时动作语义；速度目标翻倍、时长减半不代表已经验证位移相等。

本次为源码更新，未部署到RK3588、未发送实车运动指令。38项相关检查通过，覆盖40%实际串口编码、2秒定时参数、停车后再伸C、默认速度上限、计划/执行一致和网页时长显示。
