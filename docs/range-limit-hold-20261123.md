# 到行程边界后的停止与恢复

现场记录：B回传96mm且目标仍有约50px垂直误差，30秒内346次目标更新、A67–72°变化，B目标全部96mm。旧居中门槛使用完整二维圆，B已无法修正的误差使门槛无法满足，A继续响应横向噪声。

修正：只有实时位置确已抵达配置边界、误差要求继续越界且没有正在执行的向内目标，才在停止判据中忽略该方向的不可达分量。其余可修正分量仍使用原10%半径、1.5倍外圈和新鲜持续离圈判据。保持时发送禁用并停止后续微调，界面显示“行程受限 · 保持”，不宣称二维已对准。

目标回到可达方向时重新计算判据，不让此前限位保持阻挡向内运动；横向离开外圈则恢复A，垂直恢复可达则恢复B。尚未抵达下限、仅目标指向下限时不能提前进入限位保持。A到限同样保留可用的B修正。范围、模型、固件和C策略不变。

新增伪终端和边界检查验证：底部抖动不发使能微调；左右离圈后恢复；垂直反向后恢复；顶部对称；边界尚未到达和已有向内运动不误保持；正常圆形居中、遮挡和原有追踪继续受回归检查覆盖。

验证结果：专项10项通过，完整回归191项通过（138.699秒）。部署运行follow_20261123_range_hold，3项文件哈希/板端编译确认。修复后约29.97秒窗口控制帧0，A70/B96/C0、禁用、控制错误0；当时目标偏差已接近原圆形容差，界面相应显示保持。现场窗口证明停止状态保持，不能代替移动目标离圈后的现场验证；后者已由伪终端覆盖。截图console.jpg和前后日志存于outputs/limit_hold_20261123。
