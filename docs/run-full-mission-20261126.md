# 完整靠桶流程的运行方式

当前固定版本为 **v0.3.8**，板端目录`/home/elf/bucket/releases/0.3.8`，默认入口固定到该目录。2026-11-27轮次`manual_20261127_200553_11818`完成全流程，用户确认“全程正常，已停稳，无人工干预”。版本沿用实车验收的同一套123个文件，仅规范发布清单版本名称，未重新编译控制程序。校验与验收边界见[版本固定记录](releases/v0.3.8.json)。

一次主程序自动完成识别、桶框中心A/B追踪、80%目标巡航、40厘米附近减速、约20厘米停车；若先到左视姿态，则不再等待画面居中，转入模型测距和连续左移靠近。随后执行额外40%速度固定2秒侧移、暂停追踪、B回0、C伸150毫米并禁用停车。额外侧移是定时动作，不表示精确10厘米，也不表示最终距离仍为20厘米。正常控制为115200串口。

Mac终端直接运行：

```sh
ssh -t rk3588 /home/elf/bucket/start_full_mission.sh
```

如果已经进入RK3588终端：

```sh
/home/elf/bucket/start_full_mission.sh
```

运行前车辆放回起点，留出机构归位空间。已有有效零点时，启动入口按新鲜回传的实际位置依次收回C、B回顶、A回73°，每步确认停车；已经归位则直接沿用，不重复动作。STM32重新上电、零点丢失时，按用户2026-11-26的明确要求默认B在顶部、C完全收回，不再重复询问。这是用户指定的物理前提，不是独立传感器证据；版本内`field/startup_policy.json`明确记录该条件。

启动入口读取新鲜串口回传：已有有效B/C零点时直接沿用；检测到稳定的STM32重启特征（A73/B0/C0、零点均未登记、命令计数0、输出禁用）后，按原8秒等待配置与正常航向/故障检查，发送禁用命令再登记B/C零点。新登记只发送禁用帧，不移动机构或底盘。持久化账本保证同一次未确认的登记不会盲目重发；重启之外的异常状态不会被默认条件覆盖。

入口会正常结束上一轮已完成且禁用已确认的控制台，或同项目未执行运动的只读预览，使用新的`/home/elf/bucket/runs/manual_日期时间_PID/automatic/`保存任务数据。正在运行、停止未确认或无法识别的进程不会被强制结束。每次启动都会新建目录，不直接复用旧任务的“恢复自动运行”。

右侧控制台刷新当前`http://127.0.0.1:18788/`；该地址使用当前Mac上的SSH转发。重新建立转发可在另一个Mac终端运行：

```sh
ssh -N -L 127.0.0.1:18788:127.0.0.1:8788 rk3588
```

RK3588本机控制台为`http://127.0.0.1:8788/`。终端Ctrl+C会要求主程序正常停车并退出；界面“停止机构”可暂停任务。

只读检查入口（不打开串口、不停止旧控制台、不启动任务）：

```sh
/home/elf/bucket/start_full_mission.sh --check
```

仅恢复STM32启动零点、随后保留只读预览（不启动整套运动任务）：

```sh
/home/elf/bucket/start_full_mission.sh --initialize-only
```

仅准备机构并保留停车预览（会自动收回机构，不启动底盘任务）：

```sh
/home/elf/bucket/start_full_mission.sh --prepare-only
```

`--initialize-only`保持原来的不移动机构语义；`--prepare-only`与正常启动均可复用有效零点完成归位。归位通过现有115200串口事务执行，不重发零点登记，不发送底盘运动指令，出错时执行原停车确认流程。

原始等效任务命令如下；同一端口已有控制台时应使用上面的启动入口，由它处理已结束的旧实例：

```sh
/home/elf/bucket/releases/0.3.8/run_mission.sh \
  --out "/home/elf/bucket/runs/manual_$(date +%Y%m%d_%H%M%S)/automatic" \
  --execute-post-geometry --wall-budget 420 --seconds 1800
```

`--execute-post-geometry`启用靠桶后的侧移、B回顶、C伸出；省略时只保留靠桶与待执行计划。单个任务总时间预算为420秒，控制台最长保留1800秒。

自动前进和连续左移阶段的航向偏差超过2°先限速，超过3°尝试停车后原地纠偏；稳定后确认停车、丢弃旧距离，再确认原目标和新测距后继续。大偏差、反馈异常或纠偏失败仍保护暂停。完整实车验收这一轮没有触发主动纠偏，其真实收敛不能由本轮全流程成功推定。详见[航向处理与验收](heading-correction-20261127.md)。

初始A转向限速、原桶身份恢复和B停车状态修复见[初始恢复](stalled-target-recovery-20261127.md)；左视边界交接见[主流程左视规则](left-boundary-handoff-20261127.md)；后处理动作见[40%侧移2秒](left40-2s-20261127.md)。完整实车轮次在左移近距阶段曾等待失锁恢复，恢复同一桶及新测距后自行完成。

默认入口选择固定发布目录，不根据最新文件日期、Git工作区或stage目录自动换版。旧候选目录作为回退保留；当前已完成任务及右侧画面在版本固定时保持运行，不因此重新归位或运动。
