# 启动时 A 轴往返自检

用户最终要求仅做A，不做B/C。沿用当前STM32固件及上位机固定8秒软件等待、并行模型预热和自检。必要条件通过并完成本周期一次性B/C零位登记后，依次发送A的配置下限0°、上限160°、回正75°，所有帧的B/C运动目标均为0。

每段必须收到成功回传、目标软件位置连续稳定，并收到禁用确认，才进入下一段；三段完成后清除旧目标，等待新画面自动追踪。页面阶段及滚动日志显示左侧、右侧、回正。运动过程不计入8秒软件等待；每段沿用8秒运动截止时间。

用户停止、通信/故障/必要检查异常会取消流程，不前进到后续目标。中途程序重启保持未完成状态，不自动重做或重复登记。普通程序重启沿用已准备状态，不触发新的A自检；检测到新的STM32/电机复位才执行。准备完成的证据来自协议软件位置及停止回传，不是独立编码器检测或实物卡滞诊断。

修改入口：power_cycle_startup.a_startup_selftest=true。B/C行程仍0–96/0–100mm，C暂不自动追踪；本功能不改变范围、不修改或烧录固件。

软件验证：完整回归186项通过（133.859秒）；新增3项伪终端检查覆盖A全顺序、取消、回传超时，同时验证B/C无运动目标且登记仅一次。板端部署后不因普通进程切换触发摆动，新的真实复位周期仍需现场验收。
