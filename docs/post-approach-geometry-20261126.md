# 靠桶后前进、半距侧移与伸臂计划

本阶段命题：对相机到同一桶身测量点的俯视距离进行三角分解，得到前向分量a和左向分量b，并生成“前进对齐、半距左移、C150”的顺序计划。该计算本身不构成底盘位移完成证明。

按用户本次指定，A73朝前、A131作为近似左视基准。两点线性近似下，连线与车体左向的夹角为 `alpha = 90 * (131 - A) / (131 - 73)`，单位为真实角度估计；`a = D * sin(alpha)`，`b = D * cos(alpha)`。已有全局参考仍记录A132约正左、131为已验收停车容差，本次没有覆盖该参考，也未将软件指令角宣称为角度编码器读数。

以上一轮停车A124和图中D20cm为例：alpha约10.86度，a约3.77cm，b约19.64cm，半距侧移约9.82cm。若使用上一轮实际模型距离21.248cm，估计前进约4.00cm、左移约10.43cm。

当前用户已确认：C收回时相机与投喂出口近似重合、偏移可忽略；出口高于桶沿，可从上方伸入。计算暂把给定斜距当作俯视平面距离，测量端点仍是桶身表面点，未宣称得到桶口中心。

顺序为前进并持续追踪至近似左视位置，确认停车，向左移动b/2，确认停车，C伸出至绝对150mm。保持底盘与B/C互锁，车头方向不作常规转向。

`post_geometry.py`只计算，不访问UART。`pending_extension_plan`已生成新顺序，但阶段仍是`waiting_displacement_measurement`：当前协议没有经过标定的底盘厘米位移回传，不能用速度百分比和时间代替位移。前进段可消费已有视觉左视对齐条件；半距侧移完成前，不自动触发C伸出。

检查覆盖三角分解、物理角度/指令角区分、正前/正左端点、b/2、C150、无效值与旧任务停止前置条件，共7项通过。计算计划保存在`outputs/post_geometry_20261126/`；本轮未下发任何新运动。
