需要确定执行器型号、位置控制/连续旋转类型、脉宽与实际转角关系以及传动比。机构能转360°本身不能确定这些电气映射。先保留已验证的朝前脉宽，再确定新坐标与范围；不得将未验证的设定度数当实际角度。
