# 大幅位置与尺度变化后的重获

## 认识与机制

上轮实机的明显长等待包含一个可定位机制：桶移开/被人遮挡后重新出现，旧框约215×204像素，随后新检测框变大且偏离旧位置；原重获路径同时约束尺寸比例、IoU和距离。尽管强检测恢复，旧位置门槛仍阻止新候选进入，直到约5秒后回到新目标获取。

修正版在自动模式失锁时并行确认当前唯一检测目标，不必等待旧位置超时。它是新的自动目标获取，增加目标代次并重置运动预测，不声称仅凭图像证明是同一个物理桶。确认要求：唯一有效模型框、连续位置/尺度变化、当前画面纹理、跨帧正相关；高外观一致性路径至少3帧/120ms并有至少2个强检测，明显变视角路径至少4帧/200ms且全部为强检测。当前确认帧分数至少0.8，低分候选、重复时间戳、过大帧间隙、多个候选和空白遮挡均不能直接发布目标。

成功确认后，将已经取得的检测证据交给新跟踪器。仅在最初350ms的过渡期允许当前≥0.65模型框配合更严格的新旧位置重叠和相邻画面相关性继续定位，避免重锁一帧就因光流尚未适应视角再失锁。这一截止时间不会自行延长，每一步都必须有当前图像与检测；缺失目标不能靠预测续跟。已知外观的尺度搜索范围由0.5–2倍扩为0.25–4倍，但仍保留原外观确认。

完全遮挡暂停、中心10%保持/15%恢复、A/B范围、C固定、回传超时门槛、异步日志和关闭同步CSRT等既有控制行为未改。
