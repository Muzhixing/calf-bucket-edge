# 近距离边缘部分可见目标的重获

## 核心问题与机制

本阶段检验：桶贴近相机、从画面边缘逐渐露出时，能否利用已存在的连续检测证据提前重获，同时保留完全遮挡暂停和圈内停止微调。

上轮录像中的主要阻塞不是低置信度或外观变化。frame1703至1759之间，模型持续检测到贴近左边缘的桶；相邻图像的归一化相关性多数大于0.9，但普通跟踪要求框四边均离画面边缘至少8像素。这段记录中frame1762才满足完整框几何条件。原有5秒重获超时进一步使恢复落到重新初始化路径。

修正保留普通光流/模板搜索的边界条件，另设检测支持的边缘路径。合法的画面内部分框，短边至少64像素、面积不超过画面70%，向内取安全像素区域；不补全不可见桶身，也不推算画面外中心。自动重获仍要求唯一候选、连续强检测、时间/位置/尺度一致性、当前图像纹理与跨帧相关性。确认后跟随可见部分中心，让目标逐渐进入画面。

边缘跟踪每步必须有唯一当前检测和匹配的当前图像；检测缺失、歧义或不匹配时暂停，没有光流或旧模板续跟兜底。完整强检测连续稳定后切回普通跟踪，重置运动预测。部分框中心会随露出面积变化，因此这一阶段仅使用当前方向误差，关闭速度预判；A/B行程、C固定、中心10%保持/15%恢复规则不变。

## 反例与额外约束

配对回放发现两版原有模板备用路径在frame1903把背景误认成桶。该路径缺少当前几何光流和模型支持，因此新增约束：没有≥0.65的关联检测时，必须同时满足固定/近期/相邻外观相关性均≥0.90，且距离最后有效光流不超过150ms。模板匹配本身不能刷新这个期限。当前检测存在时保留原有备用搜索；原有“背景改变但前景未变”和短时无检测平移测试保留。

## 实机结果

2026-11-22晚间`motion_01`运行119.15秒，3231条追踪样本、579次连续目标命令。用户完成测试后反馈“完美”。新路径产生13次边缘重获，候选确认跨度132–268ms；12次随后发出对应代次的跟随命令，目标发布至命令发送2.5–12.8ms，另1次因下一帧检测消失而保持暂停。frame1419记录到部分目标切回完整目标。13次边缘重获及交接的原生图像核查均定位实际可见白桶。

最后圈内保持18.95秒，禁用确认后没有使能调整命令。46段失锁中，43段取得新的禁用确认；另外3段进入失锁前的最新回传已禁用，期间没有发送命令。停用后至重获前均无使能命令。遮挡能力的直接图像证据来自前述同录像回归；本轮实机缺检片段抽查多为桶仍可见，不将这些片段当作新的完整遮挡1秒验收。用户对整轮测试的评价与日志证据分别记录。

无控制错误、无大于80ms的控制循环间隔告警、系统/电机故障0，UART错误计数始终61，命令全部位于原行程范围。异步日志正常排空且无样本/图像丢弃。追踪计算中位32.95ms、P99为115.23ms、最慢213.28ms；控制目标图像年龄中位83.52ms、P99为210.11ms，最大317.87ms。因此本次实测支持更早边缘跟随，不表述为完全无延迟或全程无短暂停顿。

测试结束正常禁用并退出，随后独立只读采集3秒、14帧均禁用：A77°、B76.0mm、C10mm，航向与零位标志有效，系统/电机故障0，没有重写零位。
