## 设计决策

采用模块化分层应用：perception、tracking、motion、transport、missions、runtime。部署在同一设备，不引入微服务或额外框架。

现有成熟数学算法与参数保留。任务编排负责阶段及底盘策略；追踪组件负责身份变化、居中与A/B目标；运动适配器保留底盘/机构互锁；串口事务只维护一份。

标准项目元数据使用pyproject.toml；命令通过console_scripts/python -m暴露；配置、HTML等由显式资源路径提供。正式包不得从tools/tests或日期目录导入。原入口只做兼容转发。
