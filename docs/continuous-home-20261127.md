# 连续归位与B一次回顶

本次修改针对两处明确的启停来源：后处理每上升20毫米就禁用停车，启动准备同样把B回顶分成20毫米、A回正分成4个指令单位。每段都经历到位、禁用确认及下一次使能，因此机构在完整归位途中反复启停。

新增ArmPort.return_axis_home只允许B/C的绝对零点或已校准A回正角；它复用原串口所有者和已有运动/到位/禁用ACK状态机。后处理仅发一次B=0，等待B回顶且禁用确认后才伸C。初始准备保留C收回、B回顶、A回73°顺序，每轴只发送一次绝对终点目标；轴间继续确认禁用，不重发零点登记。已有C150而只需B回顶的续接分支保留C150。

单次完整行程的超时按配置速度与加速度计算：距离/最大速度 + 最大速度/加速度 + 4秒，至少8秒；途中持续处理新回传、故障、越界和停止请求。旧跟踪小步约束仍由原move/follow控制，不能通过该接口选择任意大步目标。写入失败、无确认或超时不盲目重发。

验证包含：B96→76→56→36→16→0期间只发送一次使能目标，到顶才禁用；中途停止可确认实际中间位置；失效回传/控制器故障/未禁用/未就绪/保留轴非整数等在发送前拒绝；原20毫米跟踪限制仍有效。PTY串口检查验证完整初始化的目标恰为C0、B0、A73，且每轴间存在禁用；后处理B96一次回顶，停车后才发C150。

候选版本为0.3.9-continuous-home-rc1。已固定且实车通过的v0.3.8发布目录、标签与默认启动入口保持原样；本次不从当前机构位置发起实车运动。新候选待实机检查连续回顶后再决定固定及切换默认入口。

软件检查：13项后处理/初始化串口检查、6项连续归位事务检查、46项原有停机与启动安全回归均通过；新增轴间禁用顺序断言单独通过。Ruff与153文件格式检查通过，wheel与80个源码/资源文件一致。板端候选清单123项通过只读启动检查；默认启动入口仍为固定0.3.8。本次未发出实机动作指令。
