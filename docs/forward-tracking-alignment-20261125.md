# 追踪桶并前进至左侧对齐：实车验收

2026-11-25，用户现场确认车辆保持追踪同一个测试桶，向前行驶后桶已基本位于车体正左侧，车辆自动停稳。此次建立的是单桶、有限分段前进的实车结果，未执行左移、B/C动作或投喂。

## 左视参考与判定

用户确认A73朝前。直接观察A163、140均偏左后；依次回调135、132后，用户确认A132基本朝正左，并指定作为左视参考。已写入 `deploy/serial_rx/left_view_reference.json`。这是现场近似方向参考，不是经角度仪测量的精确外参。原始软件工作范围0–160未扩大，未烧录。

追踪目标水平方向接近画面中心，同时A回传达到131（参考132前1个指令单位的停车容差）即停止前进。桶只在画面居中而A仍偏前时，不能视为已完成左侧对齐。最后停车时A131，用户确认桶已基本正左、相机仍对着同一个桶且停稳。

## 控制方式与检验

新增 `deploy/serial_rx/track_forward_probe.py`。复用原有TargetLock、FollowPolicy和115200原始串口发送器；单一串口所有者在同一个控制帧内发送前进速度与A目标。B/C始终保持0，出料字段0，横移字段0。每个A追踪目标变更不超过4个指令单位，一次最多一个待确认控制帧；车头目标固定在该段开始时的航向。

每段先完成目标水平对准和稳定观察，再以8%速度前进，运行上限从首段5秒到后续10秒。结束后发送禁用并等待回传。目标丢失、过期超过0.35秒、身份变化、水平偏差大于45像素、串口/航向异常或STOP文件均结束本段。正常硬件故障保护保留。现有固件没有通信静默超时自动停车保证；这次的有限时长和停车确认不能作为新增MCU失联看门狗的证据。

最初带纸的一面没有稳定模型检出，首轮静止模板检查又发现桶被转动，程序拒绝旧模板且未执行车辆动作。重新查看当前白桶后，用明确的白桶区域初始化原有追踪；静止观察5秒通过。桶转到无纸一面后，模型能检出白桶。后续分段初始化要求当前检出与上一段末尾目标IoU大于0.5且唯一匹配。此次没有验证任意桶姿态下的完全自动发现。

本机10项测试通过，包括串口PTY收发、保持A不变时切换速度、同帧A/前进更新、禁用停车回传、时限、目标丢失/过期/更换、角度边界与禁止盲重试。实车结果另列如下，不能由软件测试替代。
