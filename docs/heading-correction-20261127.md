# 自动行驶中的有限航向纠偏

上轮`manual_20261127_194910_10632`在航向由3.2°变化至0.1°、最短角差-3.1°时触发上位机严格3°保护，停车确认正常。当前阶段要验证的是：小幅偏差可以通过原固件航向闭环收敛，并在保持原任务身份、距离有效期及运动预算的条件下继续任务，而不是更换基准或跳过异常。

本地配套STM32 SystemControl源码表明：航向字段按2°编码；即使forward/lateral均为0，控制器仍使用固定航向误差与角速度产生四轮差速。新逻辑复用现有串口所有者和绝对目标事务，不修改固件、不新增写串口路径。

自动前进及连续侧移采用同一个HeadingRecovery：

- 相对本轮原航向偏差超过2°时，平移速度目标上限降至20%。
- 超过3°进入停车交接，等待实际禁用ACK。仅在C收回、ABC当前位置可按原协议保持时，发送一条vx=vy=0、保留原航向及ABC的使能命令，让STM32闭环原地纠偏。
- 相对原航向和原编码目标均回到1.5°内，至少3个不同串口采样覆盖0.5秒后，再禁用并等待ACK；随后丢弃纠偏前的测距、清理运动确认窗口，继续验证同桶和新测距后渐进恢复。界面显示正在纠偏，任务进程不退出。
- 单次主动纠偏最多6秒、整个停车/纠偏/禁用最多10秒，同一串口任务生命周期最多3次。前进到侧移接管时保留计数。旧样本不能累计成功，纠偏命令不盲目重发，也不重设航向基准。
- 8°及以上偏差、相邻新回传超过5°跳变、无效/过期航向、串口/固件/机构异常、纠偏超时、次数耗尽仍禁用并锁存暂停。停止请求始终优先。

原定时侧移及伸臂阶段保持各自保护，不在C已伸出后自动旋转底盘。新逻辑针对本轮触发故障的自动前进与连续靠近阶段。80%巡航、40厘米减速和约20厘米停车规则，以及132°左视交接、后处理40%侧移2秒/B回顶/C150毫米保持既定配置。小幅纠偏实际收敛能力须以本次设备日志及现场反馈验证，软件模拟不等于真实纠偏完成。

软件验证：56项相关回归通过（107.142秒），覆盖真实PTY串口事务中的3.3°小偏差、零平移原航向命令、禁用确认、恢复原任务前进、9°硬偏差停车、左视交接、连续侧移和B互锁；纯策略还验证旧样本不能累积、6秒超时不重发、三次上限、非整数B/C已伸出不自动纠偏、环绕及突跳。界面契约1项通过。生产CI范围Ruff与152文件格式检查通过，wheel与80个源码/资源文件逐字节一致。板端不可变候选0.3.8-heading-recovery-rc1清单123项已构建，未切换默认入口、未启动实车，等待用户将车辆重新放回起点后继续原授权的完整测试。
