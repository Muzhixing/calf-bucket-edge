# 连续自动靠桶与目标恢复

## 当前行为

锁桶后即并行运行同桶追踪和经典/神经辅助测距。距离先到约20cm时，底盘停车并用停稳后的新测量确认，A可仍朝左前方；若先到左视角A132°且仍较远，则确认停稳对齐后，转入连续左移靠近。正常行驶不再周期性停车等待模型。

模型的一次结果约滞后3秒。程序保留采图时间，从最近5次有效测量的采图时间差估计接近速度，用中位数抑制个别距离噪声，外推到当前时刻；当前画面桶宽变化只提供保守的距离缩短提示，不能增加允许的净空。采图距离、测量年龄、当前预测、变化率及速度上限分别记录。速度百分比不换算成未经标定的米数。

根据预测净空及下一次更新期间的接近量，速度上限从8%降至7%、6%，经过原加减速策略执行。6%已在带载实测中产生接近；更低速度未建立稳定带载能力，因此不以降到低速后停转代替到达。预测进入20cm边界先请求停车，只有新的停稳测量证实后才完成任务；预测偏早时继续接近。测量超过8秒、身份/外观恢复未经验证或距离变化不一致时减速停车等待。

## 修复机制

v0.3.1 的截断自动获取丢失原始框：`[20,456,398,719]` 被交接为 `[20,456,398,712]`，导致同帧从普通跟踪切换到边缘跟踪时触发 `edge_frame_gap`。现在保留原始框，选择正确跟踪器；初次更新失败时保留已经验证的选择参考，允许后续同桶恢复。

B到实际边界后接受无法消除的垂直误差，继续以可靠的水平观测对齐。B必须到位且停止，原底盘/B运动互锁保持。左视交接不再使用A尚差一度或车辆仍运动时的一帧结果，改为禁用确认后多帧新鲜对齐验证。

相机转动可使桶离开旧恢复搜索区域。新增恢复证据使用已知桶图像：互相匹配的局部特征、RANSAC相似变换、足够分布的内点、投影与当前检测一致，以及对齐后的共同像素相关性。至少3个独立新帧、跨越0.18秒确认后才恢复旧任务身份。已证明的候选在0.5秒内用相邻图像连续性验证，避免反复运行特征恢复使新帧过期。错误外观、歧义候选、重复帧不能恢复运动。诊断保留丢失前后的图像与元数据。

启动顺序为先取得串口回传并完成接管，再启动辅助模型，避免模型初始化阻塞触发通信保护。应用退出时，即使运动停止未获确认，也清理自有视觉进程并保留失败结果，避免残留相机/端口被下一次启动误用。

结束任务时先确认禁用，然后在保持UART回传的同时等待模型与视觉线程退出，最后释放串口并保存结果；前进转左移复用已禁用的串口连接和计数状态。模拟测试用超过0.7秒回传有效期的延迟线程验证收尾不中断遥测，不放宽通信保护。

## 降级边界

视觉丢失时减速、必要时停车；同桶与新鲜测距恢复后自动继续。测距线程失败后退避重试，暂时无效测量不覆盖最近有效测量，其有效期仍由采图时间限制。控制器故障、通信中断、航向异常、预算耗尽及停止未确认保持原有停车/锁存，视觉恢复不能解除这些锁存。

到达后仍只生成既有C150/左移100mm待执行计划；缺少已验证位移反馈时不发送这两项运动。计划记录实际到达A角度。正常控制仍通过115200串口，不烧录固件。
