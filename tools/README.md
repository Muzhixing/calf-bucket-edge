# 工程工具

- `field/`：人工指定的机构/底盘动作与响应拟合；复用正式控制包。
- `calibration/`：双目标定采集、求解、导出和受控姿态采集。
- `chassis_debug/`：固件/寄存器及历史现场检查，不属于普通视觉运行。
- `release/`：wheel与原生资源组装、完整性校验及新目录部署。

先在项目根目录安装`bucket-robot`。工具只通过`bucket_robot`导入正式能力，正式能力不反向导入工具。硬件相关工具必须按其命令行参数和既有现场流程执行；普通CI只发现根目录`tests/`，不会自动执行现场脚本。

固件导出工具`field/verify_firmware.py`仍需显式传入上游仓库。其输出是新的验证资料，不能直接覆盖已有fixture来让回归通过；更新fixture须同时核对固件版本与协议变化。
